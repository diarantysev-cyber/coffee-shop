
# Coffee Shop Website

A responsive website for a specialty coffee shop.

## Project Description

This website introduces a coffee shop, presents different coffee origins, displays menu items, and allows customers to submit a pre-order form.

## Features

- Responsive design for desktop and mobile devices
- Navigation menu
- Coffee origin cards
- Coffee menu
- Pre-order form
- Light and dark themes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
